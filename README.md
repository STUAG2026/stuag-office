# STUAG-Office – Updates

Dieses Repository enthält nur die Auslieferungsdateien von STUAG-Office (Angebots- und Rechnungssoftware für Baubetriebe, STUAG.com):

- `STUAG-Office_Setup_<Version>.exe` – Setup für Windows 10/11 (64 Bit)
- `version.json` – Versionsdatei für das Online-Update im Programm (Version, Datei, SHA-256, Datum, Hinweise)

Das Programm lädt Updates von `releases/latest/download/version.json`. Die Nutzung erfordert eine Lizenzdatei von STUAG.com.
